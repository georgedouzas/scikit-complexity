    CayleySpace(group, *, ball=None, fill=0.0, max_sites=MAX_SITES, label='space')

    Bases: BaseSpace

    Cayley graph of a finitely generated group, on a ball of words or a whole finite group, whose sites hold cells.

    The group is a native Sage or GAP group: a Sage PermutationGroup or MatrixGroup, or a GAP group from libgap, such as the free group libgap.FreeGroup(['a', 'b']), a finitely presented group free / relators, an automaton group libgap.AutomatonGroup('t = (1, t)(1, 2)') of the AutomGrp package, or the finite quotient of one, such as libgap.PermGroupOnLevel(group, 3). Finitely presented groups are solved by Knuth-Bendix completion with KBMAG.

    Sites are the distinct elements of a ball of a radius in the generators and their inverses, numbered by word length and then by order of discovery, so a ball is a prefix of every larger ball. Without a ball the group must be finite, and the sites are all its elements. A cell at the site g reads the site g s for every element s of a memory set, and a neighbour outside a ball, or reached through a site outside it, reads the value fill.

    Parameters:

    Name Type Description Default
    group object

    The group.

    		 required
    ball int | None

    The radius of the ball, or None for a finite group.

    		 None
    fill float

    The value read outside a ball.

    		 0.0
    max_sites int

    The largest number of sites.

    		 MAX_SITES
    label str

    The label of the space in its system.

    		 'space'

    Attributes:

    Name Type Description
    generators_

    The names of the generators, their GAP names when these are identifiers, or a, b, and so on.
    words_

    The shortest word of every site, in site order.
    lengths_

    The word length of every site, its distance from the identity in the Cayley graph.
    ball_sizes_

    The number of sites within every radius, from 0 to the radius of the ball or of the finite group.
    generator_table_

    The site of g s for every site g and letter s, in the order a, a^-1, b, b^-1, ..., and -1 outside.
    edges_

    The edge from every site g to g s for every generator s inside the space, with the generator's number.
    level_

    The level of the tree whose action keys the elements of an automaton group, or 0 for other groups.

    Examples:

    >>> from sage.all__sagemath_gap import PermutationGroup

>>> space.size_, space.words_[:4], space.ball_sizes_

    ContinuousSpace(extent=(), *, n_dim=None, boundary='open', label='space')

    Bases: BaseSpace

    Continuous space of real positions, a box with a boundary or the whole of R^d.

    A box has an extent along every dimension, from 0 to the extent. Its boundary acts on every position state of the members on it: 'open' leaves positions alone, 'periodic' joins opposite sides and measures pair distances by the minimum image, and 'reflecting' mirrors positions back into the box and reverses the velocity across the wall. Without an extent the space is unbounded and has n_dim dimensions. The positions are states of the members, so the space has no sites, and a site has no neighbours in it.

    extent Sequence[float]

    		 ()

    		 None

    'open', 'periodic', or 'reflecting'.

    LatticeSpace(shape, *, geometry='square', boundary='periodic', fill=0.0, spacing=1.0, neighborhood='moore', capacity=None, label='space')

    Bases: BaseSpace

    Box of the integer lattice Z^d, or of the triangular lattice in 2D, whose sites hold lattice group members.

    Sites are numbered in row-major order, so site (i, j) of a lattice of shape (n, m) is member i * m + j. A triangular site (i, j) keeps its integer coordinates on a skewed grid and sits at (j + i / 2, i sqrt(3) / 2) in the plane, so it has six neighbours at unit distance.

    boundary str

    		 'periodic'

    		 0.0
    spacing float | Sequence[float]

    The distance between neighbouring sites, or one distance per dimension.

    NetworkSpace(graph, *, layers=(), capacity=None, fill=0.0, hyperedges=(), label='space')

    Bases: BaseSpace

    Network whose nodes agents occupy or lattice sites sit on, with the neighbours of a node given by its edges.

    Lattice groups on a network hold one member per node, in the order of graph.nodes. The graph is the default layer, and layers adds named relations over the same nodes. Edges of a layer are numbered in the order of graph.edges, and every layer lowers to arrays: the source and target node index of every edge, and the adjacency of every node in compressed sparse row form. On an undirected graph the source of an edge is the end that comes first in node order. Build the graph with NetworkX, such as nx.erdos_renyi_graph(100, 0.1, seed=0).

    Parameters:

    Name Type Description Default
    graph Graph

    The NetworkX graph, the default layer.

    		 required
    layers Sequence[LayerSpec]

    The named layers over the nodes of the graph.

    		 ()
    capacity int | None

    The largest number of agents on a node, or None for no limit.

    		 None
    fill float

    The value lattice rules read in the padding slots of nodes with fewer neighbours than the largest degree.

    		 0.0
    hyperedges Sequence[Sequence[object]] | Hypergraph

    The hyperedges of the network, which hyperedge interactions and groups on hyperedges read: sequences of at least two nodes, an XGI Hypergraph, or an XGI SimplicialComplex, whose faces of at least two nodes are its hyperedges. The members of an XGI hyperedge follow the order of the nodes of the graph.

    		 ()
    label str

    The label of the space in its system.

    		 'space'

    Attributes:

    Name Type Description
    graphs_

    The graph of every layer by label, None first for the graph of the network.
    edges_

    The source and target node index of every edge of every layer by label, in the order of graph.edges.
    adjacency_

    The neighbours of every node of every layer by label in compressed sparse row form: the start of the neighbours of every node with the number of entries last, the sorted neighbours of every node in turn, the successors on a directed graph, and the edge that joins every node to every neighbour.
    hyperedges_

    The node index of every member of every hyperedge, in the order of the hyperedges.
    incidence_

    The sparse incidence matrix of the hyperedges, with one row per node and one column per hyperedge.
    memberships_

    The indices of the hyperedges every node belongs to, in increasing order.

    Bases: LatticeSpace
