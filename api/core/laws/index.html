    Laws

    Define laws, the rules by which states change.

    BaseLaw(label)

    Bases: BasePart[str, object]

    Base of every law, a rule by which states change, which an element, an interaction, or a system returns.

    A law takes the states it changes and the expressions it reads as arguments of its own __init__, which stores each under its own name, as in scikit-learn. It returns the states it changes from _get_targets, what it requires of a system, such as continuous or discrete time, from _get_requirements, and its value at given values of the symbols it reads from _run, which sets it as value_.

    Parameters:

    Name Type Description Default
    label str

    The name of the law, or the empty string for a law without one.

    		 required

    Attributes:

    Name Type Description
    targets_

    The states the law changes.
    reads_

    The symbols the law reads.
    owner_

    The path of the element or interaction that returns the law, or None.
    value_ object

    The value of the law at the values of the symbols of its last run.

    Examples:

    >>> from sage.all__sagemath_symbolics import var
>>> from skcomplex.core.laws import RateLaw
>>> x, k = var('x'), var('k')
>>> law = RateLaw(x, -k * x).check().prepare('decay')
>>> law.targets_, sorted(map(str, law.reads_)), law.owner_
((x,), ['k', 'x'], 'decay')
>>> law.run({'x': 2.0, 'k': 0.5}).value_
-1.0

    BilinearLaw(target, first, second, rate, outcomes=None, *, label='')

    Bases: BaseLaw

    Gain or loss of a target density at a signed rate of the product of two densities.

    The amount of the first density f in class h that meets the amount of the second density g in class k adds to class i of the target at the rate r[h, k] with probability B[h, k, i], so the law adds sum_hk r[h, k] B[h, k, i] f_h g_k to the rate of the target at i. A positive rate gives a gain that leaves the first density in place, and a negative rate with the first density as the target gives a loss.

    Parameters:

    Name Type Description Default
    target Expression

    The symbol of the density the law changes.

    		 required
    first Expression

    The symbol of the first density.

    		 required
    second Expression

    The symbol of the second density.

    		 required
    rate object

    The signed rate, a number or a parameter expression, or an array r[h, k] of them.

    		 required
    outcomes object

    The array B[h, k, i] of the probabilities of the class in the target, or None for the class of the first density, which needs a target of its size.

    		 None
    label str

    The name of the law, or the empty string for a law without one.

    		 ''

    Examples:

    >>> from sage.all__sagemath_symbolics import var
>>> from skcomplex.core.laws import BilinearLaw
>>> f, g = var('f'), var('g')
>>> BilinearLaw(f, f, g, -0.5).check().prepare().run({}).value_
(-0.5, None)

    CascadeLaw(drive, relax, stable, max_iterations=100000, activity=None, *, label='')

    Bases: BaseLaw

    Cascade of a lattice: drive laws once per step, then the laws that relax it until it is stable.

    Every cascade that changes the lattice is recorded as an event with its size, the number of site updates, its duration, the number of iterations, and its area, the number of distinct sites updated. A site update is a site that changes in an iteration, or a site that activity marks as active before it, such as a toppling site.

    Parameters:

    Name Type Description Default
    drive Sequence[BaseLaw]

    The laws applied once per step, local rules or drives.

    		 required
    relax Sequence[BaseLaw]

    The laws applied in turn until the lattice is stable.

    		 required
    stable Callable[..., bool]

    A function of the arrays of the targets of the laws that relax the lattice, in lattice shape, that returns whether the lattice is stable.

    		 required
    max_iterations int

    The largest number of iterations in one step.

    		 100000
    activity Callable[..., object] | None

    A function of the arrays of the targets that returns a boolean array of the active sites of an iteration, or None to count the sites that change.

    		 None
    label str

    The name of the cascade events, or the empty string for the path of the element.

    		 ''

    Examples:

    >>> from sage.all__sagemath_symbolics import var
>>> from skcomplex.core.laws import CascadeLaw, LocalRuleLaw
>>> from skcomplex.core.spaces import VonNeumannNeighborhood
>>> height = var('height')
>>> topple = LocalRuleLaw(height, VonNeumannNeighborhood(center=True), lambda z, *n: z - 4 * (z >= 4))
>>> CascadeLaw([], [topple], lambda z: bool((z < 4).all())).check().prepare().targets_

    Bases: BaseLaw

    Event at the crossing of zero by a guard, when states take new values or the run ends.

    Solvers locate the crossing within their tolerance. Crossings leave the form of a system as is, so they combine with rate laws, and the trajectory records every crossing with its time and the states before and after it.

    Parameters:

    Name Type Description Default

    A symbolic expression of states and time whose crossing of zero triggers the event, or a function f(t, values) of time and the mapping from the dotted name of every state and parameter to its value, or CallSpec(f, relative=True) to read the names of the component. Over a group it returns one value per member. It runs in Python, and a function does not lower the order of derivatives or read delays.

    		 required

    A mapping from state symbol to its new value, applied all at once, or None to keep the states. A value may be a function like the guard's.

    		 None

    		 0

    		 False

    		 ''

    EncounterLaw(candidate, field, rate, transition, test=None, *, label='')

    Bases: BaseLaw

    Bilinear transfer of a density between its classes at the rate of its product with a second density.

    The amount of the candidate density f in class h meets the amount of the field density g in class k at the rate eta[h, k], and moves to class i with the probability A[h, k, i]. The law adds the gain and the loss

    df_i/dt = sum_hk eta[h, k] A[h, k, i] f_h g_k - f_i sum_k eta[i, k] g_k,

    where the loss acts on the candidate and the gain on the test density, the candidate itself by default, so the total over the classes is conserved. The candidate, the field, and the test are states of groups on the sites of lattices of classes, one member per class. A field density that no law changes is a fixed external input.

    Parameters:

    Name Type Description Default
    candidate Expression

    The symbol of the candidate density, a state of a group read member by member.

    		 required
    field Expression | None

    The symbol of the field density, or None for a linear redistribution, with one field class of value one.

    		 required
    rate object

    The encounter rate, a number or a parameter expression, or an array eta[h, k] of them.

    		 required
    transition object

    The array A[h, k, i] of transition probabilities, numbers or parameter expressions, which sum to one over i.

    		 required
    test Expression | None

    The symbol of the density the candidate moves into, or None for the candidate's own density.

    		 None
    label str

    The name of the law, or the empty string for a law without one.

    		 ''

    Examples:

    >>> import numpy as np
>>> from sage.all__sagemath_symbolics import var
>>> from skcomplex.core.laws import EncounterLaw
>>> f, g = var('f'), var('g')
>>> rate, transition = EncounterLaw(f, g, 1.0, np.full((2, 2, 2), 0.5)).check().prepare().run({}).value_
>>> rate, np.shape(transition)
(1.0, (2, 2, 2))

    EquationLaw(lhs, rhs=None, *, target=None, label='')

    Bases: BaseLaw

    Implicit relation in which the highest time derivatives of states appear, such as Newton's second law.

    The states are Sage functions of time, such as function('theta')(t), and their derivatives are Sage derivatives, theta.diff(t, 2). The compiler solves all equations of a system jointly for the highest derivatives, which must appear linearly, and adds the rate laws on the same states to the solution. An equation may name the state whose equation it is, its target, and the equations of one target, from any element or interaction, add into one before the solve, so a term of it may hold no highest derivative, such as the part a coupling Lagrangian adds to the Euler-Lagrange equation of a coordinate.

    Parameters:

    Name Type Description Default
    lhs object

    The left side, or a Sage relation lhs == rhs.

    		 required
    rhs object

    The right side, or None when lhs is a relation.

    		 None
    target object

    The state whose equation this is, so that the equations of one target add, or None for an equation of its own.

    		 None
    label str

    The name of the law, or the empty string for a law without one.

    		 ''

    Attributes:

    Name Type Description
    lhs_

    The left side.
    rhs_

    The right side.

    Examples:

    >>> from sage.all__sagemath_symbolics import function, sin, var
>>> from skcomplex.core.laws import EquationLaw
>>> t, g, l = var('t g l')
>>> theta = function('theta')(t)
>>> EquationLaw(l * theta.diff(t, 2) == -g * sin(theta)).check().prepare().rhs_
-g*sin(theta(t))

    FluxLaw(target, flux, *, limiter='minmod', riemann='rusanov', speed=None, label='')

    Bases: BaseLaw

    The flux is a symbolic expression of the field's states for one dimension, or one expression per dimension. The states of a field with fluxes form a system of conservation laws, whose wave speeds come from the eigenvalues of the flux Jacobians. Rate laws on the same states add sources.

    Parameters:

    Name Type Description Default
    target Target

    The symbol of the conserved state.

    		 required
    flux object

    The flux, an expression or one expression per dimension.

    		 required
    limiter str | None

    The slope limiter of the MUSCL reconstruction, 'minmod', 'van-leer', or None for first order.

    		 'minmod'
    riemann str

    The numerical flux, 'rusanov' or 'godunov', the exact solver for one state.

    		 'rusanov'
    speed object

    A function f(t, values) of the mapping from the name of every conserved state and parameter of the flux to its array over the cells, which returns the wave speed of the Rusanov flux, or one function per dimension. None takes the speeds from the eigenvalues of the flux Jacobians.

    		 None
    label str

    The name of the law, or the empty string for a law without one.

    		 ''

    FractionalNoiseLaw(target, value, order=None, *, hurst, convention='ito', label='')

    TransferLaw(source, sink, amount, rate=None, *, label='', owner='')

    Bases: BaseLaw

    Movement of an amount of a quantity from a source holder to a sink holder, in continuous or discrete time.

    A transfer is one outflow of its source and one inflow of its sink. Its amount is a rate in a system of rate laws, the amount moved per step in a system of update laws, and the size of every jump when a rate is given. The trajectory records the amount at every frame under <path>.<label>, the path of the part that declares the transfer, or owner when given.     UpdateLaw(target, value, *, label='', increment=False, source=None, order=None, phase=None)

    Bases: BaseLaw

    Next value of a state after one discrete time step.

    A state takes one update law, unless each of its update laws declares how it combines with the others. An increment law gives the state plus a change, and a law with a source changes only a state that holds the source value and keeps every other value. Several such laws of one state combine in one step by adding their changes, x + sum_k (f_k - x), all computed from the states at the start of the step, so increments add and moves from distinct source values compose. Two laws with the same source, or a law that declares neither, are an error.

    With an order, the members of a group update one after the other, in increasing order of the value of order at the start of the step, ties in the order of the members, and each member reads the values the members before it set. Without one, every member updates at once from the states at the start of the step.

    With a phase, the law runs in that phase of the step, which a PhasesScheduleSpec of the discrete time orders. The phases run one after the other, each reading the states the phases before it set, and the laws of one phase update at once. A law without a phase runs in the default phase, first unless the schedule places it.

    Name Type Description Default
    target Target | TopologyRequestSpec

    The symbol of a scalar state, the column of symbols of a vector state, or a TopologyRequestSpec, whose value is the probability that the request fires.
