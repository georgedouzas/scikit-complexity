    Specs

    Specs that name classes of the core: the parts of a system as a compilation reads them.

    CensusRecordSpec(path, owner, law, targets, vectors, component, space, processes=(), driven=(), reads=(), members=1, handles=(), degrees=dict()) dataclass

    Bases: BaseSpec

    Law of a component with the element it changes and the states it targets.

    Parameters:

    Name Type Description Default
    path str

    The path of the component that returns the law.

    		 required
    owner str

    The path of the element or group whose state the law changes, or that a rule acts for.

    		 required
    law BaseLaw

    The law.

    		 required
    targets tuple[EntrySpec, ...]

    The layout entries of the states the law targets.

    		 required
    vectors frozenset[str]

    The names of the targets declared as vector states.

    		 required
    component ElementKind

    The kind of the owner: an element, a fixed or variable group, or a group on the sites of a space.

    		 required
    space BaseSpace | None

    The nearest space enclosing the component.

    		 required
    processes tuple[ProcessKey | None, ...]

    For a noise law, the Wiener process of every target component: None for an independent process, ('local', path, label) for a local label, or ('wiener', path, index) for a process of a WienerProcessSpec.

    		 ()
    driven tuple[tuple[str, int], ...]

    For a noise law, the state entry name and column of every target component.

    		 ()
    reads tuple[frozenset[tuple[str, int]], ...]

    For a noise law, the state components that the amplitude of every target component depends on.

    		 ()
    members int

    The number of members the law is evaluated for.

    		 1
    handles tuple[str, ...]

    The handles of Wiener processes that the law uses outside the process of a noise law.

    		 ()
    degrees Mapping[str, int]

    The degree of the cells of every symbol the law reads of a group on a cell complex, by the name of the symbol.

    		 dict()

    CensusSpec(system, records, errors, agents=dict()) dataclass

    Bases: BaseSpec

    Laws of every component of a system, and the errors of the components that fail to declare or collect.

    Parameters:

    Name Type Description Default
    system System

    The system.

    		 required
    records list[CensusRecordSpec]

    The laws of the components that declare and collect without error.

    		 required
    errors list[tuple[str, SkcomplexError]]

    The path of every failing component with its error.

    		 required
    agents dict[Expression, tuple[str, str]]

    def basis_index(self, label: object) -> int:
    """Return the index of the basis state of a label or an index.

    Args:
        label:
            The label of a basis state, or its index.

    Returns:
        index:
            The index of the basis state.

    Raises:
        ValidationError:
            The label names no basis state.
    """
    space = self.space
    if isinstance(label, str) and label in space.basis:
        return space.basis[label]
    if isinstance(label, int | np.integer) and not isinstance(label, bool) and 0 <= label < space.dimension:
        return int(label)
    labels = ', '.join(map(repr, space.basis)) or 'none'
    error_msg = (
        f'{type(self.element).__name__} {self.label!r}: {label!r} is no basis state. Use a label ({labels}) or an '
        f'index from 0 to {space.dimension - 1}.'
    )
    raise ValidationError(error_msg)

    def initial_vector(self) -> npt.NDArray[np.complex128]:
    """Return the initial state of the element as a normalised vector.

    Returns:
        vector:
            The initial state.

    Raises:
        ValidationError:
            The initial state names no basis state, or is a vector of the wrong size or norm.
    """
    initial = getattr(self.element, self.state)
    if isinstance(initial, str | int | np.integer):
        vector = np.zeros(self.dimension, dtype=complex)
        vector[self.basis_index(initial)] = 1.0
        return vector
    vector = np.asarray(initial, dtype=complex).ravel()
    norm = float(np.linalg.norm(vector))
    if vector.size != self.dimension or abs(norm - 1) > NORM_TOLERANCE:
        error_msg = (
            f'The initial vector of {self.label!r} has {vector.size} components and norm {norm:.6g}, but its '
            f'space has dimension {self.dimension} and states have norm 1. Normalise the vector.'
        )
        raise ValidationError(error_msg)
    return vector
