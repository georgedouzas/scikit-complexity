    Experiments

    Study models through many runs: designs, scenarios, replicates, sensitivity analysis, and calibration.

    BaseDesign

    Bases: BaseConfig[Bounds, None], ABC

    Base of designs, which give rows of values by factory argument or dotted path.

    A design stores its settings, such as the number of rows, in __init__. Preparing it on a mapping from name to what it samples sets its rows in rows_, which running it keeps:

    • a sampled design reads a pair (low, high) or a SciPy distribution per name;
    • a grid design reads a sequence of values per name;
    • a rows design reads nothing, because its rows are its setting.

    A child implements _prepare(bounds), which sets rows_.

    Attributes:

    Name Type Description
    rows_ list[Row]

    One mapping from factory argument or dotted path to value per row, set by prepare.

    Examples:

    >>> from skcomplex.experiments import BaseDesign
>>> class MidpointDesign(BaseDesign):
...     def _prepare(self, bounds=None):
...         self.rows_ = [{name: sum(bound) / 2 for name, bound in (bounds or {}).items()}]
>>> MidpointDesign().check().check().prepare({'r': (0.0, 1.0)}).run().rows_
[{'r': 0.5}]

    BaseExperiment

    Bases: BaseConfig[None, None], ABC

    Base of experiments, which run a model, given by a factory of systems or a system, many times.

    An experiment stores its source and settings in __init__, validates them in check, resolves the source and what it runs in prepare, and runs in run, which keeps its results in the attributes that end in _. A child implements _prepare and _run, and reads the model with the private methods of the base. A model of the library is passed as its factory, or as a system that skcomplex.models.create returns, since experiments do not import the model library.

    Examples:

    >>> from skcomplex.experiments import BaseExperiment
>>> from skcomplex.models.biology.ecology import logistic_growth
>>> class SystemExperiment(BaseExperiment):
...     def __init__(self, source):
...         self.source = source
...
...     def _check(self):
...         pass
...
...     def _prepare(self, context):
...         self.factory_ = self._check_source(self.source)
...
...     def _run(self, inputs):
...         self.system_ = self.factory_()
>>> len(SystemExperiment(logistic_growth).check().prepare().run().system_.elements)
1

    CalibrationExperiment(source, data, bounds, *, initial=None, loss='squares', replicates=1, dt=None, random_state=None, arguments=None)

    Bases: BaseExperiment

    Fit of parameters, given by dotted path, so that a model reproduces observed time series, with SciPy.

    Every evaluation runs the model to the last data time and interpolates its states or observables at the data times. Stochastic models average replicates runs with fixed streams, so the loss is smooth in the parameters. Least squares use scipy.optimize.least_squares, and the Gaussian likelihood with an unknown variance uses scipy.optimize.minimize.

    Experiment(source, design=None, bounds=None, scenarios=None, replicates=1, *, analyses=None, until=None, dt=None, solver=None, outputs=None, warmup=0.0, random_state=None, executor='serial', observables=None)

    Bases: BaseExperiment

    Runs of a model over a design, scenarios, and replicates, with one random stream per design row and replicate.

    The streams are spawned from random_state in a fixed order, so the results do not depend on the executor, and every scenario of a design row and replicate shares its stream.

    Every run clones every analysis, prepares the clone on the run's trajectory, runs it, and keeps the attributes that its run sets as scalar outputs named <prefix>.<attribute>, without the trailing underscore. The prefix is the lowercase class name of the analysis, such as entropyanalysis, numbered -1, -2, ... when several analyses share a class, as scikit-learn names the steps of make_pipeline.

    def ensemble(
    self,
    name: str,
) -> tuple[npt.NDArray[np.float64], npt.NDArray[np.float64], npt.NDArray[np.int64]]:
    """Return a kept series of every run interpolated on the times of the shortest run, with the seeds of the runs.

    Args:
        name:
            The path of the kept series.

    Returns:
        times:
            The common times.

        values:
            One row per run and one column per common time.

        seeds:
            The seed of the run of every row.

    Examples:
        >>> from skcomplex.experiments import Experiment
        >>> from skcomplex.models.biology.epidemiology import sir
        >>> result = Experiment(sir, replicates=3, until=10, random_state=0).check().prepare().run().result_
        >>> times, values, seeds = result.ensemble('I.n')
        >>> values.shape == (3, times.size), seeds.tolist()
        (True, [0, 1, 2])
    """
    times = min((np.asarray(run.times, dtype=float) for run in self.runs), key=len)
    values = np.asarray(
        [
            np.interp(times, np.asarray(run.times, dtype=float), np.asarray(run.series[name], dtype=float))
            for run in self.runs
        ],
    )
    seeds = np.asarray([run.seed for run in self.runs], dtype=np.int64)
    return times, values, seeds

    def series(self, name: str) -> npt.NDArray[np.generic]:
    """Return a kept series of every run, stacked when all runs have the same number of frames.

    Args:
        name:
            The path of the kept series.

    Returns:
        series:
            One row per run, or an object array of per-run series of different lengths.
    """
    values = [run.series[name] for run in self.runs]
    if len({value.shape for value in values}) == 1:
        return np.stack(values)
    array = np.empty(len(values), dtype=object)
    array[:] = values
    return array

    def summary(self, quantiles: Sequence[float] = (0.05, 0.5, 0.95)) -> list[dict[str, object]]:
    """Return the mean, standard deviation, and quantiles of every numeric scalar output per row and scenario.

    Args:
        quantiles:
            The quantiles to report.

    Returns:
        summary:
            One row per design row and scenario, with `<output>.mean`, `<output>.std`, and `<output>.q<quantile>`
            columns and the number of replicates as `runs`.
    """
    groups: dict[tuple[tuple[tuple[str, object], ...], str], list[_RunResultSpec]] = defaultdict(list)
    for run in self.runs:
        groups[(tuple(run.row.items()), run.scenario)].append(run)
    summary = []
    for (row, scenario), runs in groups.items():
        entry: dict[str, object] = {**dict(row), 'scenario': scenario, 'runs': len(runs)}
        for name in runs[0].scalars:
            values = np.asarray([run.scalars[name] for run in runs])
            if values.ndim != 1 or not np.issubdtype(values.dtype, np.number):
                continue
            values = values.astype(float)
            entry[f'{name}.mean'] = float(values.mean())
            entry[f'{name}.std'] = float(values.std(ddof=1)) if values.size > 1 else 0.0
            for quantile in quantiles:
                entry[f'{name}.q{quantile:g}'] = float(np.quantile(values, quantile))
        summary.append(entry)
    return summary

    SensitivityAnalysis(method='sobol', output=None, random_state=None)

    Bases: BaseAnalysis

    Sensitivity of a scalar output of an experiment to the values of its design, with SALib.

    The analysis prepares on the result of an experiment whose design matches the method, with one run per row:

    • 'oat' reads a OneAtATimeDesign and gives the change of the output from the lower to the upper bound of every input, with the others at their midpoints.
    • 'morris' reads a MorrisDesign and gives the Morris elementary effects.
    • 'sobol' reads a SaltelliDesign and gives the first-order and total Sobol indices.

    Parameters:

    Name Type Description Default
    method str

    'oat', 'morris', or 'sobol'.

    		 'sobol'
    output str | None

    The name of the scalar output, such as the path of a kept series, whose last value it is.

    		 None
    random_state int | None

    The seed of the bootstrap confidence intervals.

    		 None

    Attributes:

    Name Type Description
    names_

    The inputs, the names of the design values.
    inputs_

    The design values of every run, one column per input.
    outputs_

    The output of every run.
    effects_

    The one-at-a-time effect of every input, for 'oat'.
    mu_star_, (mu_star_conf_, sigma_)

    The mean absolute elementary effect, its confidence interval, and the standard deviation of the elementary effects of every input, for 'morris'.
    first_order_, (first_order_conf_, total_order_, total_order_conf_)

    The first-order and total Sobol indices of every input and their confidence intervals, for 'sobol'.
    ranking_ (first_order_conf_, total_order_, total_order_conf_)

    The inputs from the most to the least influential, by effects_, mu_star_, or total_order_.

    Examples:

    >>> from skcomplex.experiments import Experiment, OneAtATimeDesign, SensitivityAnalysis
>>> from skcomplex.models.biology.ecology import logistic_growth
>>> bounds = {'growth.r': (0.1, 1.0), 'growth.K': (50, 150)}
>>> experiment = Experiment(logistic_growth, OneAtATimeDesign(), bounds, until=20, outputs=['population.n'])
>>> result = experiment.check().prepare().run().result_
>>> SensitivityAnalysis('oat', 'population.n').check().prepare(result).run().ranking_[0]
'growth.K'
