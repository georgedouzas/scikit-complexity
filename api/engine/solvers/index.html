    AgentView(agent, stepper)

    Agent as rules see it: its states as attributes, its group's parameters, its neighbours, and its location.

    The stepper gives every agent one view of the class of its group, whose states and parameters are properties, so two views of an agent are the same object. Reading a state reads the agent, and setting it sets the agent, at the end of the phase in a simultaneous phase. Parameters are read only, and an unknown name raises Python's own AttributeError.

    def displacement_to(self, other: 'AgentView | object') -> npt.NDArray[np.float64]:
    """Return the vector from the agent to another agent or a location, the shortest one on a torus.

    Args:
        other:
            An agent, or grid coordinates or a position.

    Returns:
        displacement:
            One component per axis of the space.

    Raises:
        SpaceError:
            The agents live on a network or in no space.
    """
    model = ModelView(self._stepper)
    dimensions = model.dimensions
    if dimensions is None:
        error_msg = (
            'Displacements need a grid or a continuous space, and the agents live on a network or in no space. '
            'Use `distance_to` for the number of hops on a network.'
        )
        raise SpaceError(error_msg)
    target = other.location if isinstance(other, AgentView) else other
    delta = np.asarray(target, dtype=float) - np.asarray(self.location, dtype=float)
    if not model.torus:
        return delta
    size = np.asarray(dimensions, dtype=float)
    return delta - size * np.round(delta / size)

    def lags(self, state: str, window: int | None = None) -> npt.NDArray[np.float64]:
    """Return the past values of a state of an agent, the values at the ends of the last steps, the last one last.

    An agent remembers a state declared with lags, `StateSpec(lags=m)`: the agent stepper keeps its last `m` values
    in the companion states `<state>_lag1` to `<state>_lag<m>`, which rules may also read one by one. Before the
    first steps the lags hold their initial values, the `initial` of the spec or else the initial value of the
    state.

    Args:
        state:
            The name of a state with lags.

        window:
            The number of last values, or `None` for every kept value.

    Returns:
        values:
            The values, the oldest first.

    Raises:
        KeyError:
            The state of the agent keeps no lags.
    """
    spec = self._stepper._spec_of(self._agent)
    declaration = declarations_of(MesaSolver._agent_type(spec), VariableKind.STATE).get(state)
    if declaration is None or not declaration.lags:
        error_msg = (
            f'The agents of {spec.path} do not remember {state!r}. Declare the state with lags, such as '
            '`StateSpec(lags=3)`, to keep its last values.'
        )
        raise KeyError(error_msg)
    lags = declaration.lags if window is None else min(window, declaration.lags)
    return np.asarray([getattr(self, f'{state}_lag{index}') for index in range(lags, 0, -1)], dtype=float)

    """Return the agents in the cells or nodes around the agent, within a radius, or around it in a layer.

    def referenced(self, state: str) -> 'AgentView | None':
    """Return the member of another group that a reference state of the agent names by its id.

    A state declared with `StateSpec(reference=group)` holds the id of a member of the group, or a negative value

        return None
    return MesaSolver._view_of(agent)

    def remove(self) -> None:
    """Remove the agent from the model, after checking that it holds none of a conserved quantity.

    Raises:
        ConservationError:
            A state tagged with a quantity is not zero, so removing the agent would destroy it. Settle the
            holdings with transfers first.

        SimulationError:
            The agent's group is not variable, so its size cannot change.
    """
    spec = self._stepper._spec_of(self._agent)
    MesaSolver._check_variable(spec, 'remove')
    held = {
        name: value
        for name in self._stepper._quantities[spec.path]
        if (value := float(getattr(self._agent, name))) != 0.0
    }
    if self.alive and held:
        error_msg = (
            f'Agent {self.id} of {spec.path} is removed while holding {held}. Settle its holdings with transfers '
            'to other agents before removing it, so conserved quantities are not destroyed.'
        )
        raise ConservationError(error_msg)
    if self.alive:
        self._stepper._recount(self._agent, -1)
        self._agent.removed_ = True
        self._agent.remove()

    BaseSolver(*, random_state=None, until=math.inf)

    Bases: BaseConfig[P, StepSpec]

    Base of the solvers, which advance a problem of one form through time.

    A solver stores its settings in its constructor, among them the random state of stochastic solvers and the end time of the run it prepares for. prepare(problem) prepares it for a problem and run(step) advances the state of a StepSpec from its time to its end time and keeps the state vector there in state_. The last call run(step, final=True) releases what preparing acquired, such as an external process.

    Subclasses implement the hooks _get_form, the form they solve, _get_support, what they solve, and _advance, and solvers that keep events, agents, or other state outside the state vector also implement _collect. Solvers that also solve other forms list them in _get_forms. Solvers that treat diffusion implicitly answer _is_implicit, so they do not warn about the stability limit of explicit steps. Solvers that fire renewal laws answer _is_renewing, solvers that integrate fractional noise _is_fractional, and solvers that read external inputs _reads_inputs. A solver is generic over the problem it advances, so one written for the compiler's problem reads its fields.

    Parameters:

    Name Type Description Default
    random_state int | Generator | None

    The seed or generator of stochastic solvers. A seed starts a stream spawned from np.random.SeedSequence(random_state), so the dynamics never repeat the numbers that np.random.default_rng(random_state) gives a factory or a user for initial states; a generator is used as it is.

    		 None
    until float

    Integrator of ordinary differential equations based on the step solvers of scipy.integrate.

    One integrator runs across the frames of a run, and every frame reads its state from the dense output of the step that covers the frame's time, and it restarts at every frame when a condition on time jumps at a time that depends on parameters. With delays, steps are at most the shortest delay, or a hundredth of the frame when the delay is shorter, and a delay shorter than the step reads the extension of the previous step.

    The implicit methods BDF, Radau, and LSODA receive the structure of the Jacobian that the compiler derives from the laws, at every start and restart of the integrator. BDF and Radau estimate the Jacobian by finite differences over groups of independent columns and factor it with sparse LU, which makes them the stiff path for finite-difference and finite element fields. An explicit method that spans more than 1000 stable steps of the diffusion of a field in one call warns once.

    VelocityVerletSolver(dt=0.001, *, random_state=None, until=math.inf)

    Bases: Solver

    Velocity Verlet integrator of particle systems, whose positions move with their velocities.

    Every step kicks the velocities by half a step, moves the positions, applies the boundary laws, and kicks the velocities again with the accelerations at the new positions, so a step costs one drift evaluation. It conserves energy over long runs of conservative forces. With the Numba backend every internal step of a frame runs in compiled code.

    Yoshida4Solver(dt=0.001, *, random_state=None, until=math.inf)

    Bases: Solver

    Yoshida integrator of fourth order, three velocity Verlet steps over two blocks of states.

    The solver splits the states into two blocks whose rates each read only the other block: a state of order 2 into its position and velocity, and states of order 1 by the sparsity of the Jacobian of the drift, as the coordinates and the momenta of a separable Hamiltonian split. Every step composes three velocity Verlet steps of the lengths w1 h, w0 h, and w1 h, with w1 = 1 / (2 - 2^(1/3)) and w0 = 1 - 2 w1, which kick the second block by half a step, drift the first, and kick the second again. The scheme is symplectic, so the energy of a separable Hamiltonian stays bounded over long runs. With the Numba backend every internal step of a frame runs in compiled code.
