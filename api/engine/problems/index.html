    Problems

    Define what a system compiles to: the problem, its kernels, and the values the runtime reads.

    BaseKernel

    Bases: BaseConfig[object, RunStateSpec]

    Base of the kernels: laws lowered to numbers, the parts of a problem that a solver runs at a state.

    A kernel stores in its constructor what the compiler lowered, such as compiled functions and the indices they read. check() validates them, prepare(problem) sets what a run needs, such as the first renewal times, and run(state) acts at a RunStateSpec, the time, the state vector, the parameters, and the random number generator, and keeps what the kernel computes, such as the next state or a matrix, in values_.

    A developer adds a law kind by subclassing it, together with the pass that builds the kernel and a solver that runs it. A kernel takes any context to prepare on, since the problem that holds it is built from its kernels.

    Attributes:

    Name Type Description
    values_ object

    What the last run computed. Each kernel narrows its type.

    Examples:

    >>> import numpy as np
>>> from skcomplex.engine.problems import BaseKernel
>>> from skcomplex.specs import RunStateSpec
>>> class DecayKernel(BaseKernel):
...     def __init__(self, rate=1.0):
...         self.rate = rate
...
...     def _run(self, inputs):
...         self.values_ = -self.rate * inputs.x
>>> DecayKernel(0.5).check().prepare().run(RunStateSpec(0.0, np.array([2.0]), np.zeros(0))).values_.tolist()
[-1.0]

    BasePrinter

    Bases: BaseConfig[ContextT, InputT]

    Base of the printers: they print Sage expressions as code of one target.

    A printer stores its target in its constructor, prepare(symbols) takes the symbols the code reads, in order, and run(expressions) keeps the code of the expressions, or a function that evaluates them, in code_. A printer names the types of the symbols it prepares on and of the expressions it prints, which differ between targets.

    Attributes:

    Name Type Description
    code_ object

    The code of the last run. Each printer narrows its type.

    CollisionKernel(dimensions, spacings, cross_section, angles=None)

    Bases: BaseKernel

    Binary collision integral of a density over two uniform velocity axes, by the method of Mouhot and Pareschi.

    The integral is Q(f, f)(v) = int int B(|g|, cos t) (f(v') f(v'*) - f(v) f(v*)) ds dv* in the Carleman form, an integral over the two orthogonal displacements x = v' - v and y = v'* - v, each up to twice the half-width of the grid. The weight of the pair (|x|, |y|) is split into terms of |x| times terms of |y| by a singular value decomposition, one term for Maxwell molecules, and the directions take a trapezoidal rule, so the integral is a set of FFT products on a grid padded by (3 + sqrt(2)) / 2. The mean rate is removed at every position, which conserves the density exactly.

    Parameters:

    Name Type Description Default
    dimensions tuple[int, ...]

    The number of points of every position axis and of the two velocity axes, the velocity axes last.

    		 required
    spacings tuple[float, float]

    The widths of the cells of the two velocity axes.

    		 required
    cross_section Callable[[Array, Array], object]

    The function B(speed, cosine) of arrays of the relative speed and the cosine of the deflection angle.

    		 required
    angles int | None

    The number of directions of the displacements, or None for one per two velocity points of an axis, at least 16.

    		 None

    Attributes:

    Name Type Description
    padded_ tuple[int, int]

    The shape of the padded velocity grid.
    gains_ tuple[Array, Array]

    The Fourier weights of x and of y of every direction and term, stacked over the directions and terms.
    loss_ Array

    The Fourier weight of the loss term.
    values_ Array

    The collision integral of the last run at every site.

    Examples:

    >>> import numpy as np
>>> from skcomplex.engine.problems import CollisionKernel
>>> from skcomplex.specs import RunStateSpec
>>> kernel = CollisionKernel((8, 8), (1.0, 1.0), lambda speed, cosine: 1 / (2 * np.pi)).check().prepare()
>>> f = np.exp(-(np.indices((8, 8)) - 3.5) ** 2).prod(axis=0)
>>> rates = kernel.run(RunStateSpec(0.0, f.ravel(), np.zeros(0))).values_
>>> abs(float(rates.sum())) < 1e-12

    def changing_edges(self, space: object) -> dict[str | None, BlockSpec]:
    """Return the variable edge group of every layer of a network whose edges change.

    Args:
        space:
            The network space.

    Returns:
        groups:
            The block of the variable edge group by layer.
    """
    return {
        getattr(block.node.component, 'layer', None): block
        for block in self.capacity.values()
        if getattr(block.node.component, 'on', None) == 'edges' and block.node.space is space
    }

    def step(self, p: npt.NDArray[np.float64]) -> float:
    """Return the largest stable step of explicit Euler for the diffusion at parameter values.

    Args:
        p:
            The parameter vector.

    Returns:
        step:
            The step `1 / (stiffness * max |D|)`, infinite without diffusion.
    """
    values = [reference.column_of(np.zeros(0), p) for reference in self.parameters]
    magnitude = float(np.max(np.abs(ExpressionPrinter._values_of(self.coefficient(0.0, *values))[0])))
    return math.inf if magnitude == 0 else 1 / (self.stiffness * magnitude)

    ExpressionPrinter(dialect='numpy', *, time=None, names=None, prefix='_cse', shared=True, compiled=False)

    Bases: BasePrinter[Sequence[Expression], Sequence[Expression]]

    Printer of Sage expressions as code of NumPy, scalar Python for Numba, or LAMMPS Lepton.

    prepare(symbols) takes the symbols the code reads, in order, and run(expressions) keeps in code_ the assignments of the repeated compound subexpressions, bound to numbered names, and the code of every expression. A compiled printer keeps instead the NumPy or JAX function f(t, *symbols) of the expressions. A NumPy function runs in a NumPy error state that ignores division, invalid, and overflow warnings when the expressions hold conditions.

    Lepton has neither comparisons nor a remainder, so conditions become step and select and remainders floor.

    Parameters:

    		 None

    The function that gives the code name of a symbol, or None for its printed name.

    		 None

    shared bool

    def lattice(self, name: str) -> AnyArray:

    shape = self.problem.lattice_shape(name)

    return np.reshape(self.value(name), (*shape, *member))

    def lattice_shape(self, name: str) -> tuple[int, ...] | None:
    """Return the lattice shape of a state that lattice laws read or change, or `None` for other states.

    Args:
        name:
            The dotted name of the state.

    Returns:
        shape:
            The number of sites along every dimension.
    """
    for step in self.lattice:
        for state in step.targets:
            if state.name == name:
                return state.shape
    owner = name.rpartition('.')[0]
    for element in self.elements:
        if element.path == owner and element.lattice_shape is not None:
            return element.lattice_shape
    return None

    def extend(self, t: float, x: Array, p: Array) -> Array:
    """Return the parameter vector followed by the value of every reduction at a state.

    Args:
        t:
            The time.

        x:
            The state vector.

        p:
            The parameter vector.

    Returns:
        extended:
            The extended parameter vector.
    """
    q = np.zeros(self.extent)
    given = min(p.size, self.parameters)
    q[:given] = p[:given]
    for reduction in self.steps:
        reduction.run(RunStateSpec(t, x, q))
    return q

    def wrap[R](
    self,
    function: Callable[[float, Array, Array], R] | None,

    """Return a function of the state and the parameters that reads the reductions at the state it receives.

            A function `f(t, x, q)` of the extended parameter vector, or `None`.

    Returns:
        wrapped:
            The function `f(t, x, p)`, or the function itself without reductions.
    """
    if function is None or not self.steps:

        return function(t, x, self.extend(t, x, p))

    def replaced(self, specs: Mapping[int, KernelSpec]) -> TransferStateSpec:
    """Return the state with replaced kernel specs, such as specs whose rows are settled.

    Args:
        specs:
            The new spec of every replaced spec, by the identity of the replaced spec.

    Returns:
        state:
            The state that holds the new specs.
    """
    born = {id(item): replace(item, spec=specs.get(id(item.spec), item.spec)) for item in self.flows}
    return replace(
        self,
        born={key: born[id(item)] for key, item in self.born.items()},
        flows=tuple(born[id(item)] for item in self.flows),
        records=tuple(replace(record, spec=specs.get(id(record.spec), record.spec)) for record in self.records),
        terms=tuple(replace(term, spec=specs.get(id(term.spec), term.spec)) for term in self.terms),
