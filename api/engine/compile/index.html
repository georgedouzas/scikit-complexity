    Compile

    Compile systems into problems of one mathematical form with fast numeric functions.

    BaseCompiler(backend=None, solver=None, observables=())

    Bases: BaseConfig[System, Mapping[str, object]]

    Compiler of a system into a problem of one mathematical form.

    check() validates the settings, prepare(system) validates the system and sets report_, the issues it finds, and run(initial_state) raises the errors of the report and sets problem_, the compiled problem, and solver_, the solver the problem runs on. A subclass implements the hooks _issues and _compile, and a compiler of a form the engine does not know names the solver of its problems in _get_solver.

    Parameters:

    Name Type Description Default
    backend BaseBackend | None

    The backend instance, or None for the backend that suits the size of the system.

    		 None
    solver object

    The solver the problem runs on, or None for the default solver of its form, whose limits compiling checks.

    		 None
    observables Sequence[ObservableSpec]

    The observables to compute at every frame, labelled by their path from the root, such as village/mean_wealth for an observable of the nested system village.

    		 ()

    Attributes:

    Name Type Description
    system_ System

    The prepared system, with the observables of the run.
    report_ ValidationReportSpec

    The issues of the prepared system.
    problem_ BaseProblemSpec

    The compiled problem.
    solver_ object

    The solver the compiled problem runs on: the solver setting, the solver the compiler names, or None for the default solver of the problem's form.

    BaseLowering

    Bases: BaseConfig[Compilation, LoweredT]

    Lowering of one family of laws, which one pass creates, later passes finish, and the compilation keeps.

    The constructor stores what the lowering reads, prepare(compilation) sets the prepared attributes the lowering gathers, and run(laws) sets lowered_, the laws lowered. A subclass implements the hooks _prepare and _run.

    A lowering that reads new symbols into laws notes their references with _add_reference, reads them back with _reference_of, and _apply_references replaces every spec it noted references for by a copy that holds them, in every field of the compilation.

    Attributes:

    Name Type Description
    compilation_ Compilation

    The compilation the lowering serves.
    added_ dict[int, tuple[KernelSpec, dict[Expression, ReferenceSpec]]]

    The spec and the references the lowering added to it, by the identity of the spec.
    lowered_ LoweredT

    The laws the last run lowered, in the shape of its input.

    BasePass

    Bases: BaseConfig[Compilation, None]

    Step of a compilation that reads fields of the compilation and writes others.

    A pass declares the fields it reads and writes through the hooks _get_reads and _get_writes, which order the passes of a compilation. prepare(compilation) takes the compilation the pass serves, and run() calls the hook _run, which reads the fields the pass reads from compilation_ and writes the fields it writes. A pass takes no input to run: the compilation it changes is its prepared target.

    Attributes:

    Name Type Description
    compilation_ Compilation

    def evaluate(self, t: float, x: Array, p: Array, agents_of: AgentsFunction | None = None) -> dict[str, object]:
    """Return the value of every observable by path.

    Args:
        t:
            The time.

        x:
            The state vector.

        p:
            The parameter vector.

        agents_of:
            A function that returns the views of the agents of an agent group by path, or `None` without agents.

    Returns:
        values:
            A mapping from observable path to its value.
    """
    done: dict[str, object] = {'__agents__': agents_of or (lambda group: None)}
    for path, get in self.getters_.items():
        done[path] = get(t, x, p, done)
    del done['__agents__']
    return done

    def prepare(self) -> Self:
    """Compile every observable into a getter, in declaration order.

    Returns:
        evaluator:
            The evaluator, with the getter of every observable path in `getters_`.

    Raises:
        ValidationError:
            Two observables share a path, an observable has neither an expression nor a group, or an expression
            reads a symbol it cannot.
    """
    self.getters_: dict[str, ObservableFunction] = {}
    if isinstance(self.problem, OperatorProblemSpec):
        self._scalars = {}
        self.getters_ = self._operator_getters(self.problem)
        return self
    self._scalars = self._scalar_sources()
    for scope, observable in self.problem.observables:
        path = self._join(scope, observable.label)
        if path in self.getters_:
            error_msg = f'Two observables have the path {path}. Give observables of one system distinct labels.'
            raise ValidationError(error_msg)
        if observable.function is not None:
            self.getters_[path] = self._function_getter(scope, path, observable.function)
            continue
        if observable.group is None and observable.expression is None:
            error_msg = (
                f'ObservableSpec {path} has neither an expression, a function, nor a group. Give one of them.'
            )
            raise ValidationError(error_msg)
        observed = self.problem.observed if isinstance(self.problem, ProblemSpec) else {}
        if observable.group is None:
            self.getters_[path] = self._expression_getter(scope, path, observable)
        elif path in observed:
            self.getters_[path] = self._observed_getter(observed[path], observable)
        else:
            self.getters_[path] = self._reduction_getter(scope, path, observable)
    self._add_law_records()
    return self

    PassCompiler(passes=None, backend=None, solver=None, observables=(), partition='plan')

    Bases: BaseCompiler

    General compiler of a system, which runs passes over a compilation in the order of the fields they share.

    prepare(system) validates the system: it compares the requirements every law declares with the states it targets, the space it lives on, and the system's time, checks that one solver runs the laws of every partition, and checks the solver and the backend against their declared support. A state of a fractional order needs an order in (0, 1), continuous time, and a solver and a backend that integrate fractional orders. It reports every issue at once in report_, each with its path and fix, and keeps the compilation planned so far in compilation_, which run continues from. Elements and groups are compiled once each, whatever the size of a group. Laws written for one member are evaluated for every member, and pair interactions are evaluated for every pair within their cutoff.

    def compile_system(
    system: System,
    backend: BaseBackend | None = None,
    observables: Sequence[ObservableSpec] = (),
    *,
    solver: object = None,
    initial_state: Mapping[str, object] | None = None,
    compiler: BaseCompiler | None = None,
) -> BaseProblemSpec:
    """Compile a system into a problem of the form its law kinds determine.

    The compiler validates the system in `prepare` and compiles it in `run`. `PassCompiler` compiles every system but
    operator ones, which `OperatorCompiler` compiles, and a model package can bring the compiler of a form of its own.

    Args:
        system:
            The system to compile.

        backend:
            The backend instance, or `None` for `NumbaBackend` on systems whose groups hold at least 1000 members in
            total and `NumpyBackend` on the others.

        observables:
            The observables to compute at every frame, labelled by their path from the root, such as
            `village/mean_wealth` for an observable of the nested system `village`.

        solver:
            The solver the problem runs on, or `None` for the default solver of its form, whose limits compiling
            checks, such as the largest dimension of a Hilbert space.

        initial_state:
            Initial values that replace those of the components, by the dotted name of the state, such as
            `{'rabbits.n': 20}`. The state of an operator system is `<system label>.state`, which takes a vector, a
            density matrix, or `'ground'` for the lowest eigenstate of the generator at the initial parameters.

        compiler:
            The compiler, whose backend, solver, and observables this function sets, or `None` for `PassCompiler`.

    Returns:
        problem:
            The compiled problem.

    Raises:
        ValidationError:
            A child has the wrong type, a value is outside its domain or has the wrong shape, or a law is malformed.

        LabelError:
            A label is not valid, duplicated, or produces a symbol collision.

        RoleError:
            A role refers to an element that does not exist, or an interaction reads groups of different sizes member
            by member.

        SpaceError:
            A vector variable has no enclosing space, or a space is not valid.

        IncompatibleLawsError:
            The system mixes law kinds that no form supports.

        BackendError:
            An agent group declares a complex state.

        ValidationError:
            Validation finds problems of more than one kind, all listed in the message.

    Examples:
        >>> from skcomplex.engine.compile import compile_system
        >>> from skcomplex.core.system import System
        >>> from skcomplex.models.biology.common.populations import ExponentialGrowthInteraction, PopulationElement
        >>> problem = compile_system(
        ...     System(
        ...         elements=[PopulationElement('rabbits', n=10)],
        ...         interactions=[ExponentialGrowthInteraction('growth', target='rabbits', r=0.5)],
        ...     ),
        ... )
        >>> problem.form.name
        'ODE'
        >>> problem.equations
        {'rabbits.n': n_rabbits*r_growth}
    """
    compiler = PassCompiler() if compiler is None else clone(compiler)
    compiler.set_params(backend=backend, solver=solver, observables=observables)
    return compiler.check().prepare(system).run(initial_state).problem_
