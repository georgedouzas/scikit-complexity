    Kinetics

    Chemical kinetics: reactions, oscillating reactors, and excitable media.

    CatalystPelletElement(label, visual=None, *, c=1.0, h=0.1, k=10.0, K=20.0)

    Bases: Element

    Catalyst pellet, the concentration c of the reactant at its surface relative to the bulk.

    The mass transfer and the surface reaction of catalyst_pellet change the concentration and read their constants from the pellet.

    Parameters:

    Name Type Description Default
    label str

    The label of the pellet.

    		 required
    visual VisualSpec | None

    How the element is drawn, or None for default_visual_.

    		 None
    c Annotated[float, StateSpec(domain=closed_open(0, oo))]

    The initial surface concentration.

    		 1.0
    h Annotated[float, ParameterSpec(domain=open(0, oo))]

    The coefficient of mass transfer from the bulk.

    		 0.1
    k Annotated[float, ParameterSpec(domain=closed_open(0, oo))]

    The rate constant of the surface reaction.

    		 10.0
    K Annotated[float, ParameterSpec(domain=closed_open(0, oo))]

    The adsorption constant, which sets the inhibition.

    		 20.0

    Examples:

    >>> from skcomplex.models.chemistry.kinetics import CatalystPelletElement
>>> CatalystPelletElement('pellet').K
20.0
