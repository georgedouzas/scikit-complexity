    BoltzmannSumInteraction(label, *, target, levels, temperature=1.0, n_spins=1.0)

    Bases: Interaction

    Boltzmann sums over a group of levels, which give the log partition function, mean energy, and entropy per spin.

    The log partition function is ln Z = log sum_j exp(-E_j / T), the mean energy is U = sum_j E_j exp(-E_j / T - ln Z), and the entropy per spin is (ln Z + U / T) / N. The sums reduce in log space, so they do not overflow at any temperature.

    Bases: Element

    FullyConnectedSpinElement(label, visual=None, *, spin=1.0, J=1.0, h=0.0, temperature=0.5, couplings=None)

    Bases: Element

    Ising spin coupled to every other spin, flipped at the Glauber rate 1 / (1 + exp(2 s h / T)).

    The local field is h = J (sum_{j != i} s_j) / N + h_ext of the Curie-Weiss energy -(J / N) sum_{i<j} s_i s_j, or h = J sum_j C_ij s_j + h_ext with a symmetric coupling matrix C of zero diagonal. The rate satisfies detailed balance with the Boltzmann distribution at the temperature T.

    Name Type Description Default

    		 required
    visual VisualSpec | None

    How the element is drawn, or None for default_visual_.

    		 None
    spin Annotated[float, StateSpec(domain=ZZ)]

    The initial spin, 1 or -1.

    		 1.0
    J Annotated[float, ParameterSpec()]

    The scale of the couplings.

            The temperature, which can change during a run.

            The scale of the couplings.

        h:
            The external field.

    rng = np.random.default_rng(random_state)

    """Return Lennard-Jones particles in a periodic square box, optionally held at a temperature by a thermostat.

            The number of particles.

                element=MassPointElement,
                size=n_particles,

            ),
        ],
        interactions=interactions,
        space=ContinuousSpace(extent=(size, size), boundary='periodic'),
