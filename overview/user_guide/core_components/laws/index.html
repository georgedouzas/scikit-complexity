    Laws

    A law is one equation or rule by which states change, such as a rate, the next value at a step, a random jump, or an algebraic equation. Elements and interactions return laws from their hook _get_laws, and the compiler lowers the laws of a system to one problem that a solver runs. The kind of law decides the form of that problem: rate laws give ordinary differential equations, update laws give a map, and jump laws give a Markov chain in continuous time. How the parts fit shows the families together, and the laws parts page compares every law class and holds its fact sheet.

    ArrayUpdateLaw

    An ArrayUpdateLaw hands the whole array of a state to a Python function at every step and stores the array it returns. Here a sandpile of 5 by 5 sites receives one grain at a random site per step.

    A BilinearLaw changes a distribution at the rate of meetings between the members of two distributions.     A BoundaryLaw sets the value a state takes after every step of the solver. Here a particle drifts at a speed of 0.3 along a periodic box of length 1, and the law wraps its position back into the box.

        self.v = v

    CascadeLaw

    A CascadeLaw drives a lattice once per step and then relaxes it until it is stable, so one step holds a whole avalanche. In the sandpile of Bak, Tang, and Wiesenfeld, a site with 4 grains or more topples and passes one grain to each of its four neighbours, and grains that fall off the edge leave the pile.

    from typing import Annotated

import numpy as np

from skcomplex.core.components.elements import Element, GroupElement
from skcomplex.core.components.laws import ArrayUpdateLaw, CascadeLaw, LocalRuleLaw
from skcomplex.core.components.spaces import BallNeighborhood, LatticeSpace
from skcomplex.core.components.systems import CompositeSystem
from skcomplex.core.engine.runtime import simulate
from skcomplex.core.specs import StateSpec

cross = BallNeighborhood(metric='manhattan', center='first')


def drop(values, *, random):
    following = values.copy()
    following[tuple(random.integers(values.shape))] += 1
    return following


def topple(z, *around):
    return z - 4 * (z >= 4) + sum(neighbour >= 4 for neighbour in around)


class SandpileElement(Element):
    law_classes = (CascadeLaw,)

    def __init__(self, label, visual=None, *, height: Annotated[float, StateSpec()] = 0.0):
        super().__init__(label, visual=visual)
        self.height = height

    def _get_laws(self, namespace):
        drive = ArrayUpdateLaw(namespace.height, drop)
        relax = LocalRuleLaw(namespace.height, cross, topple)
        return [CascadeLaw([drive], [relax], lambda z: bool((z < 4).all()), label='avalanche')]


pile = GroupElement('pile', element=SandpileElement, space=LatticeSpace((6, 6), boundary='fixed'), on='sites')
trajectory = simulate(CompositeSystem(elements=[pile]), until=300, dt=100, random_state=0)
len(trajectory.events), max(event.size for event in trajectory.events)

    In 300 steps the pile records 91 avalanches, and the largest updates 114 sites.

    The same law runs the earthquake model of Olami, Feder, and Christensen. The drive loads every site of a fault until the most stressed one reaches 1. A site at 1 or above slips to 0 and passes a fifth of its stress to each neighbour.

    def load(values, *, random):
    return values + (1.0 - values.max())


def slip(z, *around):
    return np.where(z >= 1.0, 0.0, z) + 0.2 * sum(np.where(neighbour >= 1.0, neighbour, 0.0) for neighbour in around)

    CrossingLaw

    A CrossingLaw resets states, or ends the run, when an expression of the states, its guard, crosses zero. A ball dropped from a height of 1 metre bounces off the floor and keeps 80 percent of its speed.

    from typing import Annotated

from skcomplex.core.components.elements import Element
from skcomplex.core.components.laws import CrossingLaw, RateLaw
from skcomplex.core.components.laws.utils import derivative
from skcomplex.core.components.systems import CompositeSystem

class BallElement(Element):
    law_classes = (RateLaw, CrossingLaw)

    def __init__(
        self,
        label,
        visual=None,
        *,
        h: Annotated[float, StateSpec(order=2)] = 1.0,
        e: Annotated[float, ParameterSpec()] = 0.8,
    ):
        super().__init__(label, visual=visual)
        self.h = h
        self.e = e

    def _get_laws(self, namespace):
        speed = derivative(namespace.h, 1)

    UpdateLaw

    An UpdateLaw gives the next value of a state after one step of discrete time. The logistic map follows a population of insects from year to year, x' = r x (1 - x).

class LogisticElement(Element):
    law_classes = (UpdateLaw,)

    def __init__(
        self,
        label,
        visual=None,
        *,
        x: Annotated[float, StateSpec()] = 0.2,
        r: Annotated[float, ParameterSpec()] = 2.5,
    ):
        super().__init__(label, visual=visual)
        self.x = x
        self.r = r

    def _get_laws(self, namespace):
        return [UpdateLaw(namespace.x, namespace.r * namespace.x * (1 - namespace.x))]

    BaseLaw

    BaseLaw is the abstract base of every law. A new kind of dynamics that needs a lowering of its own derives from it, and every other model chooses an existing law, such as RateLaw or UpdateLaw. The main public methods prepare and run set the states a law changes, the symbols it reads, and its value at given values of those symbols.
